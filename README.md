# IPA2026 Student Starter

This repository contains the starter code, public tests, and specifications for the IPA2026 Final Exam. Read the [exam document](https://docs.google.com/document/d/13eO_1YmLIYLaAvSPk_3e3WBbwUex_UGu51oI725ywo4/edit) before starting Part 1.

Implement the TODO and `NotImplementedError` functions in `app/` according to `specs/`. Run `python -m pytest -v` locally. Part 4 also requires you to create your own `Dockerfile`, `compose.yaml`, and Student CI workflow as described in the exam document.

Use only your assigned router interface. Keep credentials in environment variables and never commit `.env` or tokens.
